# Agent Chat

Desktop mock agent chat client inspired by the VS Code Agents Window.

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run test
npm run typecheck
npm run build
npm run e2e
```

## Scope

- Mock provider only.
- No real model integration.
- No filesystem writes.
- No terminal integration.
- No VS Code workbench source dependency.
